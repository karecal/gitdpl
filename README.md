# Academia DPL – Control de versiones con Git

## Descripción

Página web realizada a partir de una plantilla HTML, CSS y JavaScript,
utilizada para practicar el control de versiones con Git y GitHub
en el módulo de Despliegue de Aplicaciones Web (2º DAW).

## Tecnologías

- HTML
- CSS (Bootstrap)
- JavaScript (jQuery)
